# DataCamp Course Notes
*Consolidated course notes to accelerate your learning journey*

## Overview
This repository aggregates detailed notes and resources from various DataCamp courses, including:
- **Cleaning Data in Python** – Learn effective data cleaning strategies.
- **Developing LLM Applications with LangChain** – Build and deploy language model applications.
- **Generative AI Concepts** – Explore the fundamentals behind generative AI models.

Whether you're a developer, researcher, or business analyst, these notes will provide valuable insights and structured learning materials to enhance your understanding and skills.

## Installation & Setup
1. **Clone the repository:**
   ```sh
   git clone https://github.com/muhammadhamzagova666/datacamp-course-notes.git
   ```
2. **Navigate to the project directory:**
   ```sh
   cd datacamp-course-notes
   ```
3. **Explore the folders:**  
   Each course is organized in its own directory with chapter-wise PDFs.
